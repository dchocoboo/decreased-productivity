General

In tab mode, click the toolbar icon to cloak or uncloak the current tab. Global mode toggles all tabs. Whitelisted domains are always uncloaked; blacklisted domains are always cloaked.

Browsers control toolbar visibility: pin or unpin DP using the browser’s extensions menu. “Show DP Icon” is retained for imported settings. Shortcuts run on web pages and skip text fields. Use CMD for macOS Command.
